# 研究协议

## 1. 研究目标

项目题目：**基于精选 Alpha101 因子与机器学习的沪深300股票收益预测**

核心问题：

1. 仅依赖 OHLCV 的精选 Alpha101 因子，能否预测沪深300成分股未来5个完整交易日的横截面相对收益？
2. LightGBM 等非线性模型，能否在严格样本外检验中优于 Logistic Regression 等线性基准？
3. 模型提升来自 Alpha101 因子、普通量价特征，还是模型非线性？

本项目不声称完整复现全部101个因子，只复现18个不依赖 VWAP、行业中性化和市值数据的因子。

## 2. 冻结的时间口径

- 信号日：交易日 `t`。
- 信息截止时点：`t` 日收盘后。
- 计划建仓：`t+1` 日开盘。
- 计划退出：`t+6` 日开盘，即持有5个完整交易日。
- 因子只能使用 `t` 日及以前的数据。
- 标签只能使用 `t+1` 至 `t+6` 的数据。
- 股票池以成分调整的生效日期为准；信号生成时不能使用未来调入、调出信息。

如果建仓日或退出日停牌、缺少有效价格或因涨跌停无法成交，该样本必须单独标记。缺少涨跌停和逐笔成交状态时，相关结果只能表述为“收益情景分析”，不能表述为完全可执行回测。

## 3. 股票池口径

- 初始股票池：2019-01-02沪深300成分股300只。
- 后续股票池：根据2019-06-17至2025-12-15的成分进出记录，在调整生效日更新。
- 2019—2025年历史成分股并集共509只。
- 新纳入股票在纳入前的历史行情可以用于构造时间序列窗口，但纳入前不得参与横截面排名、标签阈值和模型样本。
- 在 `t` 日属于有效成分股且在 `t+1` 日满足建仓资格的股票，才进入主样本。

### 当前数据闸门

现有行情文件固定覆盖300只最新成分股，只覆盖历史509只并集中的289只，并缺少220只历史成分股行情；同时包含11只2026-06-15才预纳入的股票。

因此，在补齐509只历史成分股的2019—2025年行情前：

- 可以开发和测试数据处理程序；
- 不得生成正式的动态沪深300研究结论；
- 不得打开2024—2025年测试集进行模型选择；
- 不得把现有固定300只结果表述为无幸存者偏差的沪深300回测。

## 4. 行情与复权口径

- 因子输入：Choice 前复权开盘价、收盘价、最高价、最低价，原始成交量和成交金额。
- 所有 OHLC 字段必须采用同一复权口径。
- 成交金额不用于构造依赖 VWAP 的 Alpha101 因子，仅作为补充流动性特征和交易成本依据。
- 上市前全0记录转为缺失，但保留统一市场交易日。
- 停牌日不做价格或成交量前向填充，不得假设可以成交。
- `volume <= 0` 的记录标记为不可交易，不直接删除整行。
- 必须验证 `low <= min(open, close)` 且 `high >= max(open, close)`。
- 必须保留原始值、清洗值和数据质量标记，禁止静默修正异常。

Choice 前复权序列可能随未来公司行为回溯调整。阶段1必须进一步核实供应商复权定义；若无法获得点时复权因子，应在报告中披露这一限制，并通过对价格尺度不敏感的特征及替代口径做稳健性分析。

## 5. 连续标签和分类标签

个股可交易5日收益：

\[
r^{5d}_{i,t}=\frac{Open_{i,t+6}}{Open_{i,t+1}}-1
\]

同一信号日，在符合标签资格的动态成分股中计算横截面中位数：

\[
\widetilde r^{5d}_{t}=\operatorname{Median}_i(r^{5d}_{i,t})
\]

连续相对收益标签：

\[
y^{cont}_{i,t}=r^{5d}_{i,t}-\widetilde r^{5d}_{t}
\]

主分类标签：

\[
y^{cls}_{i,t}=\mathbb{1}(y^{cont}_{i,t}>0)
\]

连续标签用于 Rank IC、分组收益和经济意义评价；分类标签用于 Logistic Regression、Random Forest 和 LightGBM。不能只保存分类标签。

## 6. 特征口径

### 核心特征

18个精选 Alpha101 因子：

`Alpha2、Alpha3、Alpha4、Alpha6、Alpha8、Alpha9、Alpha10、Alpha12、Alpha13、Alpha14、Alpha15、Alpha16、Alpha18、Alpha20、Alpha22、Alpha23、Alpha33、Alpha34`

### 补充量价特征

补充特征与核心因子分开保存，候选项为：

- 1日、5日和20日收益；
- 5日和20日波动率；
- 日内振幅；
- 开盘到收盘收益；
- 成交量相对20日均量；
- `log(1 + amount)`；
- 成交金额相对20日均值。

任何特征缩尾、标准化、缺失处理和筛选参数都只能在训练数据上确定。横截面排名和当日横截面缩尾仅能使用当日有效股票池。

## 7. 时间切分

- 训练集：2019-01-02至2022-12-30。
- 验证集：2023-01-03至2023-12-29。
- 测试集：2024-01-02至2025-12-31。
- 最终归属以信号日、建仓日和退出日共同判断，不能仅按信号日切分。
- 训练—验证、验证—测试边界执行至少5个交易日的 purge，确保标签区间不重叠。
- 禁止随机 `train_test_split` 和随机 K 折。
- 训练期内部采用扩展窗口或滚动时间序列交叉验证。

2024—2025测试集只用于一次冻结后的最终评价。查看测试结果后，不得回头改变因子方向、标签、特征、超参数搜索空间或交易成本假设。

## 8. 模型与对照实验

主模型：

1. Logistic Regression：线性基准；
2. Random Forest：传统非线性基准；
3. LightGBM：主要非线性模型。

必须完成以下公平对照：

1. 普通量价特征 + Logistic Regression；
2. Alpha101因子 + Logistic Regression；
3. Alpha101因子 + LightGBM；
4. Alpha101因子 + 普通量价特征 + LightGBM。

三个模型必须使用相同的样本资格、标签和时间切分。固定随机种子并保存所有配置。

## 9. 评价口径

### 分类评价

- ROC-AUC；
- PR-AUC；
- LogLoss；
- Brier Score；
- Accuracy、Precision、Recall、F1及混淆矩阵。

以日期等权方式汇总，避免样本较多的日期获得额外权重。

### 金融评价

- 每日预测分数与连续相对收益的 Spearman Rank IC；
- IC均值、标准差、ICIR和正IC比例；
- HAC/Newey-West置信区间；
- 五分组收益、单调性及 Top-Bottom 收益；
- 多头Top组相对沪深300的超额收益；
- 换手率、最大回撤、年度稳定性；
- 交易成本前后收益。

主ICIR定义为 `mean(IC) / std(IC)`，另行报告年化ICIR，并明确年化因子。重叠5日标签不得按独立样本计算普通t值。

## 10. 可解释性、稳健性和成本

- SHAP背景样本只能来自训练期；
- 测试集SHAP只用于解释，不得用于重新调参；
- 同时报告置换重要性或特征删减实验；
- 主稳健性检验包括3/5/10日标签、仅Alpha与完整特征、2024/2025分年结果、交易成本和上市不足250日过滤；
- 日频重叠持仓与每5日非重叠持仓分别报告；
- A股个股多空组合仅作为因子诊断，主要可投资结果为多头组合相对沪深300的超额收益；
- 交易成本区分佣金、卖出印花税、过户费和滑点，并使用对应历史时期费率。

## 11. 硬性验收闸门

以下任一条件未通过，不进入正式测试：

1. 历史509只成分股行情未达到预定覆盖率；
2. 无法区分非成分、未上市、停牌和普通缺失；
3. 因子未来扰动测试失败；
4. 训练、验证或测试边界存在重叠标签；
5. 预处理使用验证集或测试集统计量；
6. 测试集被用于筛因子、改标签或调参；
7. 回测默认停牌或涨跌停均可成交；
8. 将重叠5日样本当作独立观测计算显著性。

## 12. 版本与变更规则

- 本协议为阶段0基线版本。
- 后续修改必须记录日期、修改内容、理由和影响范围。
- 因数据限制产生的修改必须在最终报告中披露。
- 因测试集表现产生的事后修改不得作为主结果，只能作为探索性附录。
