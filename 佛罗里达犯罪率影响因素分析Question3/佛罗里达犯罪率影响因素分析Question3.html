respiratoryrates <- readRDS("RespiratoryRates.rds")

plot(respiratoryrates$Age,

     xlab = "Age (months)",
     ylab = "Respiratory rate (breaths per minute)",
     pch  = 19)

fit <- lm(Rate ~ Age, data = respiratoryrates)

b0 <- coef(fit)[1]
b1 <- coef(fit)[2]
sig <- summary(fit)$sigma
age_grid <- seq(min(respiratoryrates$Age), max(respiratoryrates$Age), length.out = 200)
mu_age <- b0 + b1 * age_grid
# percentile curves: q(p, Age) = mu(Age) + sigma * qnorm(p)
lines(age_grid, mu_age + sig * qnorm(0.01), col = "pink", lwd = 2)
lines(age_grid, mu_age + sig * qnorm(0.05), col = "green3", lwd = 2)
lines(age_grid, mu_age + sig * qnorm(0.5),  col = "brown", lwd = 2)
lines(age_grid, mu_age + sig * qnorm(0.95), col = "green3", lwd = 2)
lines(age_grid, mu_age + sig * qnorm(0.99), col = "pink", lwd = 2)
legend("topright",
       legend = c("1%", "5%", "50%", "95%", "99%"),
       col   = c("pink", "green3", "brown", "green3", "pink"),
       lty   = 1,
       lwd   = 2,
       bty   = "n")

The scatterplot shows a clear negative relationship between age and respiratory rate, so a simple linear model is a reasonable first choice. This suggests that younger children tend to have higher respiratory rates, and the average respiratory rate decreases as age increases.

Using the fitted model, I estimated the \(1\%\), \(5\%\), \(50\%\), \(95\%\), and \(99\%\) percentile curves from \[ q(p,\text{Age}) = \mu(\text{Age}) + \sigma \Phi^{-1}(p). \] All five curves slope downward, which is consistent with the data. The \(50\%\) curve gives the median respiratory rate, while the \(1\%\) and \(5\%\) curves represent unusually low values and the \(95\%\) and \(99\%\) curves represent unusually high values for a given age.

This plot provides a useful reference range for normal respiratory rates in children aged \(0\) to \(3\) years. A child with a respiratory rate near the middle curve would be typical for their age, while values far above or below the outer curves may be considered unusual.

Rationale for the models. We chose to include age, minority, native, division, sex, and tenure as adjustment variables because they may be related to both beauty and evaluation, so they are potential confounders. We fit eval on beauty only (m0), then the full model with all six adjusters (mf), so that we can compare how the estimated effect of beauty changes when we control for the other variables. In mf we found that age, minority, and division were not significant at the 0.05 level, while beauty, native, sex, and tenure were significant. We therefore fitted a reduced model (m_drop) that keeps only beauty and these three significant adjusters (native, sex, tenure). In m0 the beauty coefficient is about 0.133; in mf and m_drop it remains positive and significant and similar in size, so we use the reduced model as our final model for a simpler summary.

4c Final model, diagnostics and conclusions

Mathematical formulation of the final model: After fitting the full model we dropped the non-significant predictors (age, minority, division) and kept only beauty and the three significant adjusters (native, sex, tenure). We write this final model as \[ \text{eval} = \beta_0 + \beta_1\,\text{beauty} + \beta_2\,\text{native} + \beta_3\,\text{sex} + \beta_4\,\text{tenure} + \varepsilon. \] Categorical predictors (native, sex, tenure) are included as in the fitted model (e.g. dummy coding with a reference category). We assume that the errors \(\varepsilon\) are independent, have mean zero, constant variance \(\sigma^2\), and are normally distributed.

Choice of the final model:We first fitted the full model with beauty and all six adjusters. Age, minority, and division were not significant at the 0.05 level, so we refitted a reduced model with only beauty, native, sex, and tenure. We take this reduced model as our final model because it is simpler and retains only the predictors that were significant in the full model; the beauty effect and conclusions are similar in both models. The residual plots above are for this final (reduced) model and suggest that the model assumptions are reasonably met.

Conclusions: In the final model (m_drop), the coefficient of beauty is about 0.14 (p ≈ 4e-05), which means one unit increase in beauty can increase about 0.14 unit in evaluation score, so beauty has a positive and statistically significant effect on evaluation score even after we control for native, sex, and tenure. The relationship between beauty and evaluation does not appear to be due only to confounding. The model’s R² is about 0.10. This means only about 10% of the variation in evaluation scores is explained by beauty, native, sex, and tenure together; the rest is due to other factors we did not include (e.g. the class size).Among the other predictors in this model, native (non-native vs native English), sex (female vs male), and tenure (yes vs no) are statistically significant.

We also look at the four residual plots to check the model assumptions:

In the Residuals vs Fitted plot, the points are scattered around the horizontal line at zero without a clear curve or pattern, and the red smoothed line is quite flat.
